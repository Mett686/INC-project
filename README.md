# INC Project – Digital Systems Design

University project for the **INC (Digital Systems Design)** course, written in VHDL.

## Overview
Hardware description and finite-state machine (FSM) design for a UART serial communication receiver (`UART_RX`), including:
- Start bit detection and mid-bit sampling synchronization
- 8-bit serial-to-parallel data reception
- Stop bit validation and data output strobe (`DOUT_VLD`)

## Simulation
Can be synthesized and simulated using **GHDL** and **GTKWave**, or within Xilinx ISE / Vivado.
